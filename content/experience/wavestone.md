- Built a CI/CD pipeline with **Terraform** and **GitHub Actions** to deploy the infrastructure.
- Defined detailed IAM roles for Data Engineers and Data Scientists to enforce least-privilege access.
- Integrated **Falco** to detect runtime anomalies in a Kubernetes cluster.
